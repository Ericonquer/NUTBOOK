# P2 文字库第二轮验收

本轮采用已确认的 15 项，中文名与正式合同一致。旧首轮的功能检查不计为第二轮视觉通过；第二阶段 AI 仍只规划。P1 已在另一块副屏完成投放、演讲者操作与退出恢复复测；AirPlay 的性能观察不作为物理屏性能结论。

## 入口

在当前预览版 NUTBOOK 打开同目录 **p2-text-review.html**，从工具栏进入编辑 → 动效。每页标题预置一个效果；调参后点套用旁三角播放当前效果，顶部三角播放整页。第 15 页使用带分隔符、小数及百分号的数字。

样本是独立 HTML，不依赖在线字体或开发服务器。旧 p2-text.html 保留作对照，仍是首轮内容。

## 逐项视觉确认

| 页 | 中文名 | 重点 |
| --- | --- | --- |
| 1 | 流彩显字 | 字内色彩流动与词组显现，收尾回到原文 |

| 5 | 折页显字 | 按行展开、有透视，中文和 emoji 不裁断 |
| 6 | 叠影归位 | 残影收束、终态无重影 |
| 7 | 错落入场 | 逐字节奏及轻盈浮升预设 |
| 8 | 柔焦显现 | 原生中确实由虚到实；逐段预设 |
| 9 | 逐字打出 | 中文、组合字符与 emoji 完整，光标可关闭 |
| 10 | 弹性字形 | 压力自动扫过后复原，无需追随鼠标 |
| 11 | 掠光强调 | 白字保持不透明，中性灰底字与白色光带形成反差，结束恢复原色 |

用户已同意本轮进入完整回归和提交收尾。明确确认的整改包括：套用其他效果不再露出翻牌帧、白字扫光按当前方案保留、选字按钮提醒足够、舞台聚光运动与节奏符合预期。自动检查与用户视觉确认分开记录，不将自动像素检查等同于真实屏幕观感。

## 范围与限制

Scroll Float 和 Scroll Reveal 分别并入第 7、8 项预设；Fuzzy Text 暂缓。旧弹性扭曲、深度文字从选项撤下，保留旧文件读取。逐词聚焦改为指定文字或鼠标悬停，不自动轮播；悬停响应正文所在窗口，演讲者缩略区域的指针尚不联动到观众窗口。实际字体、非常长的段落和外接屏性能以原生验收为准。

自动检查覆盖十五项编辑/参数历史/Rust 保存重开、正式 Markdown 导出、字素与源节点保护、参数极值、白字透明度、WebKit 实际柔焦、数字格式与不兼容对象、换行和圆形聚光。报告与人工状态分别记录，自动通过不代表视觉通过。
