# 演示导出验收样本

从一份 Markdown 生成可编辑的演示 HTML。这里使用中文、图片、多级标题、列表与代码块检查分页和正文编辑。

## 背景

### 今天的问题

- 一份稿件需要独立浏览器放映。
- NUTBOOK 的演示模式需要逐页导航和备注。
- 保存以后，正文和备注都应该在同一文件里恢复。

### 目标

让观众看到真实 HTML 动画，让演讲者看到当前页备注与下一页预览。

## 视觉材料

![本地 SVG 插图](./illustration.svg)

图片应嵌入导出 HTML，离线打开仍然显示。

## 实现细节

### 演示桥

页面 ID 是稳定的绑定键。导航函数负责切换真实页面，订阅者在实际页变化后收到通知。

```js
function goTo(id) {
  if (!pageIds.includes(id)) return false;
  showPage(id);
  return true;
}
```

### 编辑与保存

正文使用可编辑字段，备注使用独立 JSON 数据块。两者保存后关闭并重开，内容不应丢失。

## 验收路径

1. 从导出中心分别导出浅色和深色演示 HTML。
2. 在 NUTBOOK 打开 HTML，编辑一页文字和该页备注并保存。
3. 关闭重开，检查内容与页面对应关系。
4. 开始演示，向前和向后翻页，然后结束返回。

## 结论

这份样本应生成多页，覆盖静态与动态两种输出。
